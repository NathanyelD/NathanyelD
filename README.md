## 🚀 Projetos

### 💰 Controle Financeiro

Sistema de controle financeiro pessoal desenvolvido em **Python + Streamlit + Pandas**.

O projeto permite registrar receitas e despesas, visualizar o saldo, analisar gastos por categoria e utilizar filtros para consultar as movimentações.

**Principais conceitos praticados:**

* Python
* Pandas
* Streamlit
* Manipulação de arquivos CSV
* Filtros e tratamento de dados
* Git e GitHub
